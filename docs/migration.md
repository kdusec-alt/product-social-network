# 原 Sites 私有資料搬遷

管理員登入後開啟 `/classic/migrate.html`。填原 Sites 帳號與密碼，先盤點再執行搬遷。來源固定為本專案原 Sites 網站，不能輸入任意外部網址。

搬遷包含共用貼文、原始郵件、內嵌留言、型體檢核與時程、檢核模板、知識標記、四個測試帳號的個人檔案，以及郵件圖片附件。每項逐筆處理並讀回核對 SHA-256；相同內容略過，遇到新站不同內容不覆蓋，原站記錄另存私有 `migration/source/` 或 `migration/conflicts/` 快照。報告存於 `migration/reports/`。

來源密碼與選填存取權杖僅在請求期間使用，不寫入快照、GitHub、報告或瀏覽器儲存。未遷移登入 Cookie、會話、付款資訊或第三方服務金鑰。

圖片保留原始二進位資料與原始附件編號；超過 1 MiB 的項目回報待處理，不會自動壓縮或刪除。此版本採逐項搬遷並可重試，不是整站原子切換；若某項失敗，其他已核對成功項目保留。完成後檢查待處理數必須為零。

盤點依原站伺服器儲存內容。只存在個別瀏覽器、尚未同步到原站的資料不會由伺服器自動出現，需另外核對與匯出。搬遷會保留顯示作者與原始 actorId；帳號權限仍由新站私密設定管理，不搬入舊管理員權限。

本次新增的遷移路徑已在隔離的模擬回應與儲存測試中核對管理員權限、內容與圖片保真、重複處理、衝突保留與來源密碼不落盤。實際搬遷仍須以兩站已授權的管理員會話驗證。
